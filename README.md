# Daylight To-Do List

https://tumelo7843.github.io/priority-to-do-list/

A lightweight, responsive to-do list app built with plain HTML, CSS, and JavaScript. Tasks are saved in your browser, so they remain available when you reopen the page in the same browser.

## Getting started

1. Download or clone this project.
2. Open index.html in a modern web browser.
3. Add a task using the input at the top of the list.

No build step or package installation is required. The Google Fonts used by the page need an internet connection; the app itself works offline after the page and font have loaded, and task data is stored locally in the browser.

## Using the list

- **Add a task:** Type a task, choose High, Medium, or Low priority, and select **Add task**. Press Enter to add it too.
- **Complete a task:** Select the circle next to it. Select it again to mark the task active.
- **Change priority:** Use the priority menu on the task row.
- **Edit a task:** Double-click its text, enter the revised text, and confirm.
- **Delete a task:** Select the × button on its row.
- **Filter tasks:** Choose **All**, **To do**, or **Completed**.
- **Search:** Enter part of a task name in the search field.
- **Clear completed tasks:** Select **Clear completed** beneath the list.
- **Track progress:** The completion ring and summary update as tasks change.

## Project files

- index.html — Page structure and controls.
- style.css — Layout, colors, and responsive styling.
- script.js — Task actions, filters, and browser storage.

## Data and privacy

Tasks are saved in the browser localStorage for this page. They are not synced to an account or shared between browsers. Clearing the browser site data can remove saved tasks.
